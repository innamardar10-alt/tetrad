# Тетрадь по нейросетям

Рабочая тетрадь для тех, кто только начинает работать с нейросетями. Семь сервисов с бесплатным входом, урок на каждую тему и домашняя работа к каждому уроку.

Красивая версия тетради в виде школьной страницы в линейку — файл `index.html`. Если в настройках этой папки включён GitHub Pages, она открывается как сайт.

Нейросеть здесь помощник. Дело ведёте вы.

> **Запомни!** Бесплатные лимиты меняются, поэтому цифр в тетради нет. «Лимит исчерпан» значит: на сегодня всё. Лимит вернётся через несколько часов или завтра, а пока переходите в другой сервис из тетради.

## Условные обозначения

- **Запомни!** — правило, которое пригодится везде.
- **Коннектор** — провод между нейросетью и вашими сервисами.
- **Домашняя работа** — задания с галочками.
- **Скопируй** — готовый текст для нейросети.
- **Инструмент из трёх букв** — пометка: напрямую из России сервис не открывается.
- **Карточка** — вклейка про одну нейросеть, у всех семи одинаковые строки.

## Урок 1. Коннектор

**Коннектор** — это провод между нейросетью и вашим сервисом: почтой, Google Диском, GitHub. Подключаете один раз, и нейросеть сама берёт оттуда файлы. Текст больше не нужно копировать в чат.

Пример: подключили Google Диск и пишете «найди на моём диске прайс и сделай из него пост». Нейросеть находит файл сама.

**Где искать.** В настройках сервиса. Раздел называется по-разному: «Коннекторы», «Интеграции», «Приложения», Connectors, Apps, MCP.

**Как подключить:**

1. Откройте настройки и найдите раздел с коннекторами.
2. Выберите сервис, например GitHub.
3. Нажмите «Подключить» (Connect).
4. Откроется окно GitHub или Google. Войдите и нажмите «Разрешить» (Authorize или Allow).
5. Вернитесь в чат. В некоторых сервисах коннектор надо ещё включить в самом чате: через значок инструментов или «+» у поля ввода.

> **Запомни!** Давайте доступ только к тому, что нужно для работы. Отключить коннектор можно в тех же настройках одной кнопкой.

**У кого есть коннекторы:**

| Нейросеть | Коннекторы | Где включать |
|---|---|---|
| Genspark | есть: GitHub, Gmail, Google Диск и другие | Skills → вкладка Connectors |
| Qwen | есть, в том числе GitHub | настройки |
| ChatGPT | есть, в том числе GitHub | Настройки → Приложения |
| Claude | есть, в том числе GitHub | раздел «Коннекторы» |
| Sider | проверьте в настройках | — |
| DeepSeek | нет | — |
| Алиса AI | нет | — |

> **Запомни!** Самый полезный коннектор для работы — GitHub. Что это такое, разберём в уроке 3.

**Домашняя работа**
- [ ] Откройте Genspark или Qwen и найдите раздел с коннекторами.
- [ ] Посмотрите, какие сервисы там можно подключить.
- [ ] Решите, какой коннектор пригодится вам первым.

## Урок 3. GitHub

[GitHub](https://github.com) — бесплатное хранилище для ваших файлов в интернете. Похоже на Google Диск, но с двумя отличиями:
- GitHub помнит каждую версию файла, и всегда можно вернуться к тому, что было вчера;
- из файлов можно бесплатно сделать сайт (урок 5).

Нейросети хорошо понимают GitHub. Подключили коннектор — и чат читает ваши промты, тексты и код прямо оттуда.

**Слова, которые встретятся:**
- **Репозиторий** — папка проекта (repository, repo).
- **README.md** — главная страница папки, GitHub показывает её первой.
- **.md** — текстовый файл: `#` перед строкой делает заголовок, `-` делает пункт списка.
- **Commit** — «сохранить изменения», каждый коммит — одна версия.
- **Public / Private** — открытая папка (видят все) или закрытая (видите только вы).

### Шаг 1. Регистрация
- [ ] Зайдите на github.com → Sign up.
- [ ] Введите почту, пароль и имя пользователя. Имя станет частью адреса вашего сайта, выбирайте короткое.
- [ ] Подтвердите почту.

### Шаг 2. Создать папку
- [ ] Справа вверху нажмите «+» → New repository.
- [ ] Repository name — название латиницей без пробелов, например `tetrad`.
- [ ] Выберите Public, если хотите показывать, или Private, если только для себя.
- [ ] Поставьте галочку Add a README file.
- [ ] Нажмите Create repository.

### Шаг 3. Положить файл
- [ ] В папке нажмите Add file → Upload files.
- [ ] Перетащите файл в окно.
- [ ] Внизу нажмите Commit changes.

Создать файл прямо на сайте: Add file → Create new file → имя файла, например `prompt-post.md` → вставить текст → Commit changes.

Исправить файл: открыть файл → значок карандаша → исправить → Commit changes.

### Шаг 4. Подключить GitHub к нейросети

**Коннектор GitHub** есть у Genspark, Qwen, ChatGPT и Claude. Подключается так же, как в уроке 1.

- [ ] Откройте нейросеть с коннектором GitHub.
- [ ] Найдите в настройках коннекторы → GitHub → Подключить.
- [ ] GitHub спросит разрешение → Authorize.
- [ ] GitHub предложит дать доступ ко всем папкам или к выбранным. Для начала выберите одну.

### Шаг 5. Как давать команды

Называйте папку и файл точно, как они написаны на GitHub.

**Скопируй:**
```
Открой мой репозиторий tetrad и перечисли, какие там файлы.

Прочитай README.md в tetrad и сделай из него пост для ВК до 800 знаков.

Возьми файл prompt-post.md из tetrad и напиши по нему пост про мою услугу: [услуга].

Сравни два файла в tetrad и скажи, чем они отличаются.
```

> **Запомни!** Через коннектор в обычном чате нейросеть чаще всего только читает файлы. Чтобы она сама сохраняла их в GitHub, нужны инструменты для кода: Claude Code, Codex, Qwen Code. Это следующий уровень. Пока делайте так: попросите «сделай файл README.md с этим текстом», скачайте файл и загрузите на GitHub (шаг 3).

## Урок 4. Практика

### Документ или презентация

Где делать: Genspark (AI Docs, AI Slides, AI Sheets), Claude, ChatGPT.

**Скопируй:**
```
Сделай документ «Прайс на мои услуги». Услуги: [список с ценами]. Для кого: [кто клиенты]. Структура: что я делаю, как проходит работа, что получает клиент, сколько стоит. Простым языком.
```

**Домашняя работа**
- [ ] Сделайте прайс или презентацию о себе.

### Видео

Где делать: Qwen (ролики около 5 секунд), Алиса AI (оживить фото).

1. Сначала картинка — это первый кадр.
2. Потом движение. Опишите, что двигается и как. Одно действие на один ролик.
3. Камера: «камера медленно приближается» или «камера стоит на месте».

**Скопируй:**
```
Оживи картинку: пар поднимается от чашки, занавеска чуть колышется, камера стоит на месте.
```

**Домашняя работа**
- [ ] Сделайте ролик из фото своего товара или рабочего места.

### Мультик

Бесплатные ролики короткие, поэтому мультик собирается из кусочков по 5 секунд.

1. **Сюжет** — DeepSeek или Алиса, промт ниже.
2. **Герой** — Qwen. Нарисуйте героя один раз. Потом для каждой сцены загружайте эту картинку и пишите: «этот же герой, но [что происходит в сцене]». Так герой останется одинаковым.
3. **Кадры** — Qwen, по картинке на сцену.
4. **Движение** — видео в Qwen или «оживить фото» в Алисе.
5. **Сборка** — любой видеоредактор на телефоне: ролики по порядку, голос, музыка.

**Скопируй:**
```
Придумай мультик на 30 секунд про [тема]. Разбей на 6 сцен по 5 секунд. Для каждой сцены напиши: что видно, что происходит, какая фраза звучит.
```

**Домашняя работа**
- [ ] Сделайте мультик из 3 сцен.

### Промт

Промт — это задание для нейросети. Чем понятнее задание, тем ближе результат к тому, что вы хотели.

> **Запомни!** кто ты → что сделать → для кого → что я даю → каким должен быть результат → чего не делать

**Скопируй:**
```
Ты — редактор. Напиши пост для ВК о моей услуге: [услуга]. Читатели — [кто]. Вот что я о них знаю: [2–3 факта]. Длина — до 1000 знаков, простые слова, в конце одна просьба: написать мне в личные сообщения. Не используй слова «уникальный», «лучший», «инновационный».
```

Если результат не тот, не начинайте заново, а уточняйте в том же чате:
- «Короче в два раза».
- «Проще, как будто объясняешь соседке».
- «Оставь второй абзац, остальное перепиши».

**Домашняя работа**
- [ ] Напишите по формуле свой промт.
- [ ] Сохраните его на GitHub в файл `prompts.md`.

## Урок 5. Сайт на GitHub бесплатно

Из открытой папки GitHub бесплатно делает сайт. Это называется GitHub Pages. Подходит для тетради, портфолио, визитки, страницы с вашими промтами.

**Домашняя работа**
- [ ] Проверьте, что папка Public.
- [ ] Вверху папки нажмите Settings → слева Pages.
- [ ] Source: Deploy from a branch.
- [ ] Branch: main, папка / (root) → Save.
- [ ] Подождите несколько минут и обновите страницу. Сверху появится адрес: `https://ИМЯ.github.io/ПАПКА/`
- [ ] Сохраните визитку из урока 2 (задание про Qwen) как `index.html` и загрузите в папку.

> **Запомни!** Если в папке есть файл `index.html`, сайтом станет он. Если нет — README.md.
